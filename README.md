Overview
This quiz app reads questions from a CSV file, asks the user to answer them within a timed session, and then calculates the final score. It is designed for quick quizzes and can be customized with different question sets.

Features
✅ Reads questions and answers from a CSV file
✅ Supports custom CSV file input via a flag (-f)
✅ Implements a timer (-t flag) to limit quiz duration
✅ Counts and displays the final score after completion
✅ Uses Golang's concurrency for efficient execution
